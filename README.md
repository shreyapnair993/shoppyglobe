# ShoppyGlobe E-commerce Application

## GitHub Repository
https://github.com/shreyapnair993/shoppyglobe_v1

## Tech Stack
- React 18 (with Vite)
- Redux Toolkit (state management)
- React Router v6 (createBrowserRouter)
- CSS (responsive design)

## Features
- Product listing fetched from dummyjson.com API
- Product detail pages with dynamic routing
- Add to cart and Remove from cart using Redux
- Quantity adjustment in cart (minimum 1)
- Search and filter products using Redux state
- Checkout with form and order placement
- 404 Not Found page
- Lazy loading with React.lazy and Suspense
- Lazy loading for images
- Responsive design for all screen sizes
- Error handling for failed API requests

## How to Run
1. Install dependencies: npm install
2. Start dev server: npm run dev
3. Open browser at http://localhost:5173
